# The Green Room · maquette de site

Maquette de site vitrine bilingue (français / anglais) pour The Green Room, à Oka. Construite avec [Astro](https://astro.build).

**Ceci est un aperçu de travail, pas le site officiel.** Le contenu est provisoire.

## Lancer en local

```bash
npm install
npm run dev
```

## Construire l'aperçu public

```bash
ASTRO_SITE=https://xaviereuphory.github.io ASTRO_BASE=/green-room-oka PUBLIC_PREVIEW=true npm run build
```

`PUBLIC_PREVIEW=true` ajoute la balise « noindex » et retire les données Google « commerce local ».
